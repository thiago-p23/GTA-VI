# GTA-VI API

## About the Project

**GTA-VI API** is a RESTful backend built to serve structured data over HTTP using standard methods and JSON. 

I built this project to practice and demonstrate core backend concepts, clean API architecture, endpoint organization, and external integrations.

## Tech Stack

- **REST / JSON:** Standard HTTP communication and data exchange.
- **Java & Spring Boot:** Core backend framework.
- **Swagger UI / Springdoc OpenAPI:** Interactive API documentation.

## Getting Started

### Prerequisites

Make sure you have the following installed on your machine:

- Git
- Java Development Kit (JDK)
- Maven or Gradle (depending on your local setup)
- An IDE like IntelliJ IDEA, Eclipse, or VS Code
- Postman, Insomnia, or cURL (optional, for testing)
